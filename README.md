# cribs — HK Property Valuation Tool

Tells you whether a City One Shatin flat is fairly priced today, and by how much, by separating
its objective worth (size, floor, age, block) from the subjective "premium" a seller is asking
for on top of that (renovation, staging, "modernness", etc.).

**What this does not do:** predict where prices are going. It only answers "is this fair today,
for what it is?"

Status: Stage 0 — scaffold only, no model yet. See `LEARNING_LOG.md` for a stage-by-stage build log.
